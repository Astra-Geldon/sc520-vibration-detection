# RVER 0002000A 板测记录

本目录记录 15 Hz 扩频版的用户板测结果。当前活动链路为 2.0～15.0 Hz、0.5 Hz 间隔、27 点、64 帧窗口。

## 共性检查

- `RVER=0002000A`
- `CLRC=SCNC=00000510`
- `MBFR=00000040`
- 频率编码使用 Hz×10：3 Hz=`0x1E`、11 Hz=`0x6E`、13 Hz=`0x82`、13.5 Hz=`0x87`、15 Hz=`0x96`
- `WPRD` 约 `0x033450xx`，窗口周期保持在当前 64 帧量级

## 当前结果

- `board_mix_3_13_13_5_15hz.txt`：四目标组合中出现 3、13、13.5、15 Hz，后段 `CNFM=4`。
- `board_frequency_change_13_13_5_11_5hz.txt`：连续测试中可观察到 13.5→11→5 Hz 的换频，等待槽清零后恢复新频率。

这些是板测记录，不替代 TD 的资源/时序报告；正式验收仍需核对 `phy_1` 报告和静止场景误检。
