# SC520 多目标振动频率识别：RVER00020006

当前备份分支：`backup/vibration-grid-r00020006-20261028`。这是用户已经编译、烧录并测试的2026-10-28版本；本次上传只整理源码快照、交接说明及已有日志，不调整识别、阈值、确认时间或显示逻辑。

## 当前功能与边界

- 画面按6行×8列分成48个固定网格，每格160×120像素，最多输出4个目标槽位。
- 检测到振动时标记对应网格；**尚未实现整个振动物体的包围框**。
- 频率范围固定为2.0～10.0Hz，步长0.5Hz，共17个频点。编码为`Hz10 = 20 + 5 × bin`。
- 保留64帧窗口。连续两窗均为强峰（能量≥512）时两窗确认，其余合格轨迹三窗确认；单窗不放行。
- 原始能量准入为`peak >> 8 > 64`，突出度使用旧工程的`peak × 7 > rest × 2`。这些是本版实际判据，不沿用更早实验文档中的归一化门限。
- 保留逐帧AGC参考修复；参考值可随完整帧变化下降。
- 框内左上显示槽位编号1～4，内右上显示十进制频率，字形5×7；编号对应UART的HZ1～HZ4。白色网格分隔标志保留，绿色参考标识已移除。
- 四处参考块共同运动一致性实验**停用**，源码保留；估计器、相关窗口统计与LK新增快照不参与当前综合，`CMOT=0`。

## 已有板测与未解决问题

用户反馈单目标3/8/10Hz可以正常识别；本轮单10Hz日志正常。四目标3/5/8/10Hz日志在22:38:08～10连续三个独立窗口同时输出预期四频率，槽位与网格位置保持一致。

四目标尚未达到稳定验收：用户通常能检测到2～3个，曾出现3Hz目标附近的框输出10Hz，以及多个位置同时输出9.5/10Hz。摄像头或画面移动仍可能产生误框。`CNFM=4`只代表四槽被确认，不能当作四个物体频率均正确。

开启一致性实验的两份对照日志中，19个独立窗口有5窗触发门控，说明实验运行过但覆盖有限；用户比较缓慢及剧烈摇晃后认为改善不明显，决定保持停用。

下一步仅建议先观察合格候选、主次峰竞争与旧槽占位的关系；本次没有新增诊断，也没有实现候选替换或扩展频率。详见[本版上板记录](CURRENT_BASELINE_R00020006_20261028.md)。

## UART

115200、8N1，VOFA+普通文本接收；每秒7行，每行归组多个字段。字段定义在`tools/gen_uart_log2.py`，生成文件为`user_source/hdl_source/uart_log_debug.v`。

| 字段 | 本版含义/期望 |
|---|---|
| `RVER` | `00020006` |
| `MBFR` | `00000040`，64帧窗口 |
| `CLRC`、`SCNC` | `00000330`，48×17=816状态 |
| `ACT`、`QACT`、`CNFM` | 原始过能量线块数、通过突出度块数、已确认槽位数 |
| `HZ1`～`HZ4` | 各槽频率×10的十六进制编码；无输出为0，最大`00000064` |
| `OBP1` | 四槽网格位置，每槽8位；bit6有效、bit5:0块号，低字节对应槽1 |
| `OBM1`～`OBM4` | 各确认槽的原始峰能量右移8位 |
| `PBLK`、`PKMG`、`RBIN`、`RHZ` | 同窗原始最强块及其峰；不保证通过突出度筛选 |
| `F04`、`F06`、`F08`、`F10` | 该原始最强块的4/6/8/10Hz能量，不是四个槽各自的频谱 |
| `CMOT` | 当前固定0，一致性停用 |

例如`HZ=0000001E`表示3.0Hz，`32`表示5.0Hz，`50`表示8.0Hz，`64`表示10.0Hz。判断连续窗口时按`WINC`去重，不把重复打印当成新窗口。
