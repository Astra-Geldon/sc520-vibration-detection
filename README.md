# SC520 多目标振动频率识别：RVER00020007

当前备份分支：`backup/vibration-grid-r00020007-20261028`。这是用户已经编译、烧录并测试的2026-10-28版本；本次上传只整理源码快照、交接说明及已有日志，不调整识别、阈值、确认时间或显示逻辑。

## 当前功能与边界

- 画面按6行×8列分成48个固定网格，每格160×120像素，最多输出4个目标槽位。
- 检测到振动时标记对应网格；**尚未实现整个振动物体的包围框**。
- 频率范围固定为2.0～10.0Hz，步长0.5Hz，共17个频点。编码为`Hz10 = 20 + 5 × bin`。
- 保留64帧窗口。连续两窗均为强峰（能量≥512）时两窗确认，其余合格轨迹三窗确认；单窗不放行。
- 原始能量准入为`peak >> 8 > 64`，突出度使用旧工程的`peak × 7 > rest × 2`。这些是本版实际判据，不沿用更早实验文档中的归一化门限。
- 保留逐帧AGC参考修复；参考值可随完整帧变化下降。
- 框内左上显示槽位编号1～4，内右上显示十进制频率，字形5×7；编号对应UART的HZ1～HZ4。白色网格分隔标志保留，绿色参考标识已移除。
- 四处参考块共同运动一致性实验**停用**，源码保留；估计器、相关窗口统计与LK新增快照不参与当前综合，当前精简日志不打印CMOT。

## 当前诊断与板测

00020007在00020006基础上增加只读候选诊断：最强合格候选QBLK/QHZ/QMAG及入槽/确认状态QSTA，另给出原始最强PBLK的非相邻次峰P2HZ/P2MG。原有筛选、选槽、确认、64帧、频率和显示逻辑保持；共同运动实验继续停用。

用户已经编译、烧录本版并提供日志。用户反馈摄像头正对时能够较准确同时识别四块，斜拍伴随手抖时通常能识别两三块；诊断本身未改识别规则，不能把不同拍摄条件的改善当作算法提升。

23:21:51～23:22:02连续11个独立窗口保持四槽输出，其中7窗同时为预期3/5/8/10Hz，另4窗有相邻0.5Hz跳动。日志中有合格候选的21个独立窗口，最强合格候选均被精确选入槽；本次没有记录到它被旧槽持续挡住的情况。这不能证明所有48块候选都不存在占位问题。

四目标漏检、相邻频点跳动、移动误框等仍需继续验证，尚未宣称全部稳定验收。原始附件及去重统计见`validation/r00020007_20261028/`；[本版记录](CURRENT_BASELINE_R00020007_20261028.md)汇总当前状态。

2～12Hz仅是讨论中的下一步建议，**尚未实施**；当前仍为2.0～10.0Hz、0.5Hz步长。00020006及更早备份分支保留。

## UART

115200、8N1，VOFA+普通文本接收；每秒7行、31字段、441字节。字段表在`tools/gen_uart_log2.py`，生成文件是`user_source/hdl_source/uart_log_debug.v`。

```text
SEC  WINC RVER VTAP ITER
ACT  QACT CNFM STK0 OBP1
HZ1  HZ2  HZ3  HZ4
OBM1 OBM2 OBM3 OBM4
PBLK RHZ  PKMG P2HZ P2MG
QBLK QHZ  QMAG QSTA
MBFR CLRC SCNC WPRD
```

上方仅列字段顺序，所有数值仍为8位十六进制。RVER=`00020007`，MBFR=`00000040`，CLRC/SCNC=`00000330`。频率编码为Hz×10：1E=3.0Hz、32=5.0Hz、50=8.0Hz、64=10.0Hz。

QBLK只来自通过现有能量及突出度的候选，无合格候选时为3F；PBLK是原始最强块，不保证合格。P2HZ/P2MG与同窗PBLK绑定，排除主峰及左右各一个bin，不代表四槽各自的频谱。

QSTA：bit0候选存在、bit1原始最强块合格；7:4精确入槽、11:8精确入槽且确认、15:12相邻同bin代表、19:16占用槽位、bit20窗口门控，其他0。各4位组最低位对应槽1。选择包含待确认槽，不能与确认混用。

完整语义与诊断边界见[CANDIDATE_DIAG_20261028.md](CANDIDATE_DIAG_20261028.md)。该文档按实现当时记录“待编译/上板”，本次最新用户测试状态以本页及本版记录为准。按WINC去重，不把重复打印当成新窗口。
